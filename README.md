# Petshop Patas & Companhia

Projeto de Pedro Severgnini Bittencourt para a Fase 1 de Fundamentos de Sistemas Web. O site é um catálogo estático em HTML5 com produtos, serviços e preços fictícios.

## Como usar

Abra `index.html` no navegador e use os links do cabeçalho para acessar o catálogo, os serviços e o contato.

- No [catálogo](index.html), consulte dois produtos de cada categoria. Cada produto tem foto ilustrativa, descrição e preço.
- Na [página de serviços](servicos.html), confira o que está incluído no banho e na tosa e compare os valores com e sem tele-busca.
- No rodapé de cada página, encontre o e-mail demonstrativo, a autoria e os links de navegação.

## Publicação no GitHub Pages

Coloque as duas páginas, a pasta `imagens/` e este README na raiz da branch `main` de um repositório público. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e `/(root)` e salve. O endereço do site aparece nessa tela após a publicação.
